# Some common question type of paper 1
## Topics always takes up whole question
- Spreadsheet (**~~x~~ vlookup/ sumif**)/ database(**order by/ group by**)
![spreedsheet/database command](http://image.ketsuromoe.win/i/2023/10/27/653b88306bb05.png)
  you may need to check this out in terms you don't know what should be revsied
- Programming (in pseudo code only)

## Some discrete question
- Difference between different file format (video, audio, image)
- Difference between encoding scheme
- Validation && Verification
- Brief image on cache CPU component(ALU, CU, Register)
- IO device(e.g. **Keyboard, Mouse, Printer,Scanner,Microphone,Screen ,Camera ,Digital tablet, Touchpad,etc.**)
- Ram v.s. Rom (Volatile)
- System software v.s. Application software
  - System software:
    - Utility program
    - Operation system(os)
    - Driver program
- Computer system
- Those things related to Network
> Remember to make clear concept of tls and digital cert.
- Streaming and buffer
- Some question about quity
- Firewall and Anti-virus software
- Computer-related diseases
